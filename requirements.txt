# 为什么这里没有 geopandas / osmnx / shapely：

#       pip install -r requirements-local.txt

# ⚠ 2026-10-04：下面这行注释是为了让 Streamlit Cloud **重建环境 / 重启容器**。
#   背景：只改 .py 文件时，云端可能只做**模块级热重载** —— 结果是
#   `site_common` 已是新版、`frame_picker` 还是旧模块，于是
#   `build_picker_html() got an unexpected keyword argument 'roofs'`
#   在线上报 TypeError（本地完全正常，因为本地是新进程）。
#   症状与老的"文件全对、进程里加载的模块是旧的"完全一致 ⇒ 必须 Reboot/重建。
#   （这个坑值得记住：**加了新函数参数后，光 push 不一定生效**。）

# 2026-10-04 第二次为触发重建而改这一行：底图标志物字号 42→64 后，线上字仍偏小

#   用旧代码重新渲染。改 requirements 会触发环境重建 / 容器重启。
